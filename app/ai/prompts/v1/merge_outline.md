# 多资料大纲合并

你会收到多份资料各自的“章 → 节”目录和页码，请把它们合并成**一份统一课程大纲**。

要求：

1. 不要把每份资料原样罗列成多个独立章；相同或相近的主题要合并成一节。
2. 同一节可以引用多份资料，`refs` 里按资料分别列出页码，最多 8 条。
3. `sourceId`、`pageStart`、`pageEnd` 必须来自输入，不得编造；页码用输入里的原始页码。
4. 章节按学习顺序排，先基础/总论，再方法/应用，最后复习/练习。
5. 标题短而具体，不超过 120 字；不要写“PPT1”“资料2”这类文件名当标题。
6. 输出严格 JSON，不要解释。

输出结构：

```json
{
  "title": "统一课程名",
  "chapters": [
    {
      "title": "章标题",
      "sections": [
        {
          "title": "节标题",
          "refs": [
            {"sourceId": "doc_xxx", "pageStart": 1, "pageEnd": 3}
          ]
        }
      ]
    }
  ]
}
```
